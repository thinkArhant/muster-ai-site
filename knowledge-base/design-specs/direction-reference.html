§01 · THE INSIGHT

Why it works

A team you govern — not a chat you hope converges. The leverage was never the model. It's how you wire the work.

Every multi-agent framework optimizes how agents talk to each other. Muster optimizes what each one reads — because the real ceiling is the context window, not the conversation. Mechanics run in deterministic scripts, judgment runs in prose. That's why it holds on cheap models: the floors don't move.

§02 · THE DECISIONS BEHIND IT

One of five — chosen for judgment, stamped with its date

I optimized what each agent reads — not how they talk.
DECISION 01 · 2026-05-05
Problem
Put eight agents in a room reading everything and each drowns in context meant for someone else. Quality falls as the window fills.
Trade-off
Gave up "every agent sees everything" for a PM that routes context. Costs coordination discipline — one role owns it.
Mechanism
The three-tier reading model + the PM as context-translator. The bottleneck was never communication; it was memory.
